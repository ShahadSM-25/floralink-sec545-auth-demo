# FloraLink SEC545 Authentication Prototype

This repository contains the frontend prototype for the FloraLink SEC545 implementation.

## Scope

The implementation demonstrates the following flows:

- UC-01 Register Account
- UC-02 Login
- MIT-01 Strong Authentication
- MIT-02 Rate Limiting and Account Lockout

## Run locally

```bash
pm install
pnpm dev
```

## Build

```bash
pnpm build
```
